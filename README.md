# This project uses Python to create a Twitter sentiment analysis model focused on public sentiment regarding Pfizer vaccinations. We will use data from Kaggle to build the model and analyze tweets to identify positive, negative, and neutral sentiments. Our goal is to test various classifiers to find the one with the highest accuracy.

# Additionally, we will set up an SQLite database to store user data, including usernames and hashed passwords. Users can register and log in on the website, with the login process verifying passwords against the stored hashes. We will display success or error messages based on login attempts.

The project will include a list of top influencers derived from the dataset, integrated into the website to show top followers. An interactive dashboard will visualize trends and patterns in the data through graphs and charts. Finally, we will highlight trending themes, such as debates, retweets, and popular topics on the website.
